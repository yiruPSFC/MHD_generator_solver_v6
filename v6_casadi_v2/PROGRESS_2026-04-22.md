### 2. Wide-window sweep does not collapse when the anchor/release path stays strict

Summary file:

`v6_casadi_v2/outputs/continuation/window_axis_sweep_candidate_022_sigma_0p5/axis_sweep_summary.json`

Cases run:

- `strict_ref`
- `wide_np_te`
- `wide_np_te_z`
- `wide_np_te_z_jx`
- `wide_np_te_z_jx_seed`
- `very_wide_all`

Observed behavior:

- every case above succeeded
- widening only the inlet windows did not force the solution out of the baseline basin
- all widened cases converged to nearly the same trusted final inlet design
- the widened cases achieved `objective_delta_Te_K ~= 2163.13`, only slightly above the strict reference

Implication:

- "wide inlet windows" by itself is not the main cause of collapse
- a strong baseline anchor can keep the solver in the same basin even with much wider box bounds

### 4. The likely failure mode is mixed release, not any single knob

The most plausible interpretation after the experiments above is:

- wide windows alone are not enough to collapse
- loose schedule alone is not enough to collapse
- collapse is more likely when several releases are mixed together:
  - wider inlet windows
  - weaker warm tracking
  - more aggressive `mach / A / sigma` release
  - stronger pressure from the objective before the basin is stabilized

This matches the earlier bad run that produced non-finite profiles and reward blow-up.

- the failed attempt drifted hard at the inlet:

  - `Z_in ~= 50.95`

  `objective_delta_Te_K ~= 1819.49`

Implication:

- this closes the loop on the earlier ambiguity
- the unstable regime appears when very wide inlet freedom is combined with a
  loose release path, not when either knob is changed in isolation

## Working Hypothesis For The Next Session

The continuation path should be split by release mechanism rather than relaxing
everything at once.

Proposed stage grouping:

1. `baseline anchor`
2. release `n_p + T_e`
3. release `Z`
4. release `J_x + seed_fraction`
5. only then relax geometry / tracking / objective aggressively

Rationale:

- this isolates which variable group actually opens a new basin
- if a release step fails, the responsible degree of freedom is known immediately
- if a release step widens the bounds but the solution does not move, the basin has not actually opened yet
